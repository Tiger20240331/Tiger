# Integration Guide - CloudPedagogy Learning Publisher\n\n## Overview\n\nThis guide explains how to integrate the PPT Export Module with the CloudPedagogy Learning Publisher to enable PowerPoint generation from course configurations.\n\n## Architecture\n\n```\nCloudPedagogy Course Generator\n├── YAML Config (course structure)\n├── QMD Files (Quarto markdown content)\n└── PPT Export Module (NEW)\n    ├── Config Parser\n    ├── Content Extractor\n    ├── PPTExporter\n    └── Output: PPTX files\n```\n\n## Integration Steps\n\n### Step 1: Add PPT Export to CloudPedagogy Dependencies\n\nUpdate `cloudpedagogy-learning-publisher/requirements.txt`:\n\n```txt\nclick>=8.1,<9\npyyaml>=6.0,<7\njinja2>=3.1,<4\npydantic>=2.0,<3\nrich>=13.0,<14\npython-pptx>=0.6.21  # NEW: PPT export support\n```\n\n### Step 2: Copy PPT Module Files\n\n```bash\ncp -r cloudpedagogy-ppt-export/* \\\n  cloudpedagogy-learning-publisher/src/course_generator/exporters/ppt/\n```\n\nExpected structure:\n\n```\nsrc/course_generator/exporters/\n├── __init__.py\n├── ppt/\n│   ├── __init__.py\n│   ├── ppt_exporter.py\n│   ├── ppt_builder.py\n│   └── examples/\n│       └── biology_unit_template.py\n└── html/  # existing\n    └── ...\n```\n\n### Step 3: Add PPT Export Command to CLI\n\nUpdate `src/course_generator/cli.py`:\n\n```python\n# Add to imports\nfrom .exporters.ppt.ppt_builder import PPTBuilder, BiologyUnitPPTBuilder\n\n# Add new CLI command\n@main.command()\n@click.argument('config_path', type=click.Path(exists=True))\n@click.option('--output-dir', '-o', default='output', help='Output directory for PPT files.')\n@click.option('--subject', '-s', default='Biology', help='Subject area for customization.')\ndef export_ppt(config_path, output_dir, subject):\n    \"\"\"Export course to PowerPoint presentation.\n    \n    Example:\n        coursegen export_ppt config/biology_unit.yml --output output/ppt/\n    \"\"\"\n    try:\n        config = ConfigLoader.load(config_path)\n        \n        # Initialize appropriate builder\n        if subject.lower() == 'biology':\n            builder = BiologyUnitPPTBuilder(\n                course_dir=os.path.dirname(config_path),\n                output_dir=output_dir\n            )\n        else:\n            builder = PPTBuilder(\n                course_dir=os.path.dirname(config_path),\n                config=vars(config),\n                output_dir=output_dir\n            )\n        \n        # Build PPT from config\n        module_config = vars(config.module)\n        output_file = builder.build_from_config(module_config)\n        \n        click.echo(click.style(f\"✅ PPT created: {output_file}\", fg='green'))\n        \n    except Exception as e:\n        click.echo(click.style(f\"❌ Export Error: {str(e)}\", fg='red'), err=True)\n```\n\n### Step 4: Extend Course Config Schema\n\nUpdate course YAML to support PPT-specific options:\n\n```yaml\nmodule:\n  id: bio7_unit1\n  code: BIO7-U1\n  title: \"Cell Structure and Function\"\n  title_zh: \"细胞结构与功能\"\n  \n  # NEW: PPT Export Configuration\n  ppt_config:\n    curriculum_standard: \"CAIE KS3\"\n    grade_level: 7\n    subject: \"Biology\"\n    color_scheme: \"default\"  # or custom\n    \n    # Bilingual support\n    bilingual:\n      enabled: true\n      default_language: \"english\"\n      languages:\n        - english\n        - chinese\n  \n  sessions:\n    - code: SE01\n      title: \"Slide 1: Learning Objectives\"\n      title_zh: \"幻灯片1：学习目标\"\n      \n      sections:\n        - number: 1\n          title: \"Objectives\"\n          title_zh: \"目标\"\n          pages:\n            - title: \"Content\"\n              title_zh: \"内容\"\n              kind: \"text_page\"\n              \n              # NEW: Media references for PPT\n              media:\n                - url: \"https://example.com/image.png\"\n                  type: \"image\"  # image, video, gif\n                  caption: \"Cell Diagram\"\n                  caption_zh: \"细胞图\"\n                  source: \"https://commons.wikimedia.org/\"\n              \n              # NEW: Teacher notes\n              teacher_notes:\n                teaching_tips:\n                  - \"Use interactive Q&A\"\n                learning_objectives:\n                  - \"Understand cell structure\"\n                assessment_ideas:\n                  - \"Quick quiz\"\n                resource_links:\n                  - title: \"Khan Academy\"\n                    url: \"https://www.khanacademy.org/\"\n```\n\n### Step 5: Create PPT Builder Adapter\n\nCreate `src/course_generator/exporters/ppt/adapter.py`:\n\n```python\n\"\"\"Adapter between CloudPedagogy config and PPT Builder.\"\"\"\n\nfrom typing import Dict, List, Any\nfrom .ppt_builder import PPTBuilder\nfrom .ppt_exporter import BilingualText, MediaReference, TeacherNotes\n\n\nclass CloudPedagogyPPTAdapter:\n    \"\"\"Convert CloudPedagogy course structure to PPT.\"\"\"\n    \n    @staticmethod\n    def config_to_ppt(config: Dict[str, Any], output_dir: str) -> str:\n        \"\"\"Convert CloudPedagogy config to PowerPoint.\n        \n        Args:\n            config: Parsed YAML configuration\n            output_dir: Output directory for PPTX\n            \n        Returns:\n            Path to generated PPTX file\n        \"\"\"\n        module = config.get('module', {})\n        ppt_config = module.get('ppt_config', {})\n        \n        # Create builder\n        builder = PPTBuilder(\n            course_dir=\".\",\n            config=config,\n            output_dir=output_dir,\n        )\n        \n        # Prepare module config with PPT settings\n        module_config = {\n            'id': module.get('id'),\n            'code': module.get('code'),\n            'title': module.get('title'),\n            'title_zh': module.get('title_zh', module.get('title')),\n            'curriculum_standard': ppt_config.get(\n                'curriculum_standard', 'CAIE KS3'\n            ),\n            'grade_level': ppt_config.get('grade_level', 7),\n            'subject': ppt_config.get('subject', 'Biology'),\n            'sessions': config.get('sessions', []),\n        }\n        \n        # Build and return\n        return builder.build_from_config(module_config)\n```\n\n### Step 6: Update Project Setup\n\nUpdate `pyproject.toml`:\n\n```toml\n[project]\nname = \"quarto-course-generator\"\nversion = \"0.2.0\"  # Updated version\ndescription = \"Schema-driven Quarto course publishing system with PowerPoint export\"\nauthors = [\n    { name = \"Jonathan Wong\" },\n    { name = \"CloudPedagogy Contributors\" }\n]\ndependencies = [\n    \"click\",\n    \"pyyaml\",\n    \"jinja2\",\n    \"pydantic\",\n    \"rich\",\n    \"python-pptx>=0.6.21\",  # NEW: PPT support\n]\n\n[project.scripts]\ncoursegen = \"course_generator.cli:main\"\n```\n\n## Usage Examples\n\n### Export from Command Line\n\n```bash\n# Basic export\ncoursegen export_ppt config/biology_unit.yml\n\n# With custom output directory\ncoursegen export_ppt config/biology_unit.yml --output output/ppt/\n\n# For specific subject\ncoursegen export_ppt config/chemistry_unit.yml --subject Chemistry\n```\n\n### Export from Python Code\n\n```python\nfrom course_generator.exporters.ppt.adapter import CloudPedagogyPPTAdapter\nfrom course_generator.core.config_loader import ConfigLoader\n\n# Load config\nconfig = ConfigLoader.load('config/biology_unit.yml')\n\n# Export to PPT\noutput_file = CloudPedagogyPPTAdapter.config_to_ppt(\n    config=vars(config),\n    output_dir='output/ppt/'\n)\n\nprint(f\"Created: {output_file}\")\n```\n\n## Testing\n\n### Unit Tests\n\nCreate `tests/test_ppt_export.py`:\n\n```python\nimport pytest\nfrom course_generator.exporters.ppt.ppt_exporter import (\n    PPTExporter,
